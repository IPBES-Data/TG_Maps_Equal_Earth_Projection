# TG Maps Equal Earth Projection

This tutorial script on basic map creation is developed to accompany the [technical guideline on maps on the IPBES ICT Portal](https://ict.ipbes.net/ipbes-ict-guide/data-and-knowledge-management/technical-guidelines/map-guidelines-for-ipbes-experts), and provides default options such as the use of the Equal Earth projection, the inclusion of all continents, and a colour blind-friendly colour scheme.

## Overview

This repository contains code and resources for building map visualizations using the Equal Earth projection, a map projection designed to provide a balanced view of the world while minimizing distortion in shape, area, and distance.

Technical issues or ideas for improvement can be emailed to aidin.niamir@senckenberg.de
